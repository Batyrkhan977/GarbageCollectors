Game settings

Competition format

FFA and 2v2 stop after the chosen duration. Time Attack gives each player a separate run on the same starting garbage, in shuffled order, until they collect it all. No garbage respawns.

Player starting positions

Four unique empty cells, one per numbered player slot (1–4). Coordinates are 0–19. Built-in random bots also use these slots. The map preview shows these start markers when the round has not begun.

Map editor

20 lines × 20 characters. 0 floor, 1 wall, 2 starting garbage. Wall positions are never sent to student clients.

The game must be paused before saving. Current changes exist only in server memory and are lost when Render restarts; update map.txt or add database storage for persistence.
