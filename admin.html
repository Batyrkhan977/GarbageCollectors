Game settings

Competition format

FFA and 2v2 stop after the chosen duration. Time Attack gives each player a separate run on the same starting garbage, in shuffled order, until they collect it all. No garbage respawns.

Player starting positions

Four unique empty cells, one per numbered player slot (1–4). Coordinates must be inside the current board. Built-in random bots also use these slots. The map preview shows these start markers when the round has not begun.

Map editor

Choose width and height independently, from 5 to 20. Use the brush to paint cells on the map to the right. Spawn brushes assign a unique starting position to that numbered player.

Paint by tapping or dragging on the board. Random generation creates a connected, playable board with four valid spawns. Save settings to apply your changes. The manager sees all walls and garbage; students do not see walls.
Advanced: edit map text (0=floor, 1=wall, 2=garbage)
The game must be paused before saving. Current changes exist only in server memory and are lost when Render restarts; update map.txt or add database storage for persistence.

Teacher's complete map

Private manager view: walls in gray, garbage in yellow, current players by number, red/blue team colours, random individual colors in other modes; tap or drag to paint, and the live preview overlays all players and garbage.
